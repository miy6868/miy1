# 한국사2 단기 완성

고등학교 1학년 **한국사2(2022 개정, 동아출판)** 시험 대비 학습 앱입니다.
범위: **Ⅰ. 일제 식민지 지배와 민족 운동의 전개** 전체 ~ **Ⅱ-1. 8·15 광복과 대한민국 정부의 수립**

`index.html`을 브라우저로 열면 바로 실행돼요. 설치나 빌드는 필요 없어요.

## 기능
- **홈**: 시험 날짜를 넣으면 D-day와 남은 날짜에 맞춘 하루 학습 계획이 나와요. 단원별 정답률이 60% 아래면 약점으로 표시돼요.
- **오늘의 복습(간격 반복)**: 틀린 문제는 1일·3일·7일 뒤에, 카드는 1·2·4일 뒤에 다시 나와요. 복습 날짜는 시험 전날을 넘지 않게 당겨져요.
- **개념**: 7개 단원 정리(형광펜 핵심어, 시험 포인트, 헷갈림 주의, 핵심 한 줄)
  - **빈칸 모드**: 핵심어를 가리고 눌러서 확인
  - **비교표**: 통치 시기, 무장 투쟁, 역사학, 임시 정부 체제, 토지 개혁 방식 등 7개
  - **벼락치기**: 핵심 한 줄 전체를 가리고 외우기
- **인물**: 50명 도감(한 일·키워드·암기 팁·헷갈리는 인물), 이름 가리고 맞히기, 헷갈리는 인물 묶음 9개(김씨 5인방 등), 이름↔키워드 짝 맞추기 게임
- **연표**: 118개 사건, 단원별 거르기, 연도 가리기
- **문제**: 직접 만든 기출형·사료형·OX 162문제와 자동 생성 문제(인물, 순서 배열, (가)~(라) 시기 찾기, 용어)
  - 틀린 문제는 오답 노트에 저장되고, 복습 날에 3번 맞히면 빠져요
  - "모르겠어요" 버튼으로 찍지 않고 넘기기, 찍어서 맞힌 문제는 "복습에 넣기"
- **암기카드**: 용어 122장 + 인물 50장, 양방향, 못 외운 카드 반복

학습 기록은 브라우저의 localStorage에만 저장돼요.

## 파일 구성
- `index.html`: 화면과 스타일
- `js/data-content.js`: 단원 정리와 비교표
- `js/data-timeline.js`: 연표
- `js/data-terms.js`: 암기카드
- `js/data-quiz.js`, `js/data-quiz2.js`: 문제 은행
- `js/data-people.js`: 인물 도감과 헷갈리는 인물 묶음
- `js/app.js`: 앱 로직
