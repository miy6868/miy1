# Minecraft 2D (Go + Ebitengine)

Go로 만든 2D 마인크래프트 스타일 샌드박스 서바이벌 게임입니다.
지상보다 **지하 컨텐츠**에 초점을 맞췄습니다: 거대한 동굴망, 깊이별 광물,
지하 바이옴, 폐광·던전·고대 금고 같은 지하 구조물이 절차적으로 생성됩니다.

## 실행

```bash
go run .            # 랜덤 시드
go run . -seed 12345
go run . -deep      # (디버그) 지하 220층 동굴에서 시작
```

리눅스 빌드에는 X11/GL 개발 헤더가 필요합니다:
`apt install libgl1-mesa-dev xorg-dev`

## 조작

| 키 | 동작 |
|---|---|
| A/D 또는 ←/→ | 이동 |
| Space/W | 점프 · 사다리 오르기 · 수영 |
| Ctrl | 달리기, Shift: 걷기 |
| 마우스 왼클릭 | 채굴 / 공격 |
| 마우스 오른클릭 | 블록 설치 / 상호작용 / 음식 먹기 / 활 |
| 1~9, 휠 | 핫바 선택 |
| E | 인벤토리 + 제작 |
| Q | 아이템 버리기 |
| ESC | 일시정지 / 패널 닫기 |

제작대·화로·상자는 오른클릭으로 엽니다. 화로 제련은 석탄 1개를 연료로 소모합니다.

## 월드

- **무한 절차 생성**: 청크(32칸) 단위로 좌우 무한 생성, 시드는 매번 랜덤 (`-seed`로 고정 가능)
- **높이 320블록**, 지표는 약 y=64, 아래로 갈수록 심층암 → 딥다크 → 용암 지대 → 기반암
- **지상 바이옴**: 평원, 숲, 사막, 설원, 산맥, 늪
- **지하 (핵심 컨텐츠)**:
  - 스파게티 동굴 + 깊을수록 커지는 대형 공동
  - 깊이별 광물: 석탄 → 철 → 구리 → 금 → 레드스톤 → 청금석 → 다이아몬드 → 에메랄드 (심층암 변종 포함)
  - **무성한 동굴**(이끼·발광 열매), **버섯 동굴**, **딥다크**(스컬크 + 워든), **자수정 정동**, 점적석 동굴
  - **폐광**: 목재 지지대, 레일, 사다리 수직 갱도, 전리품 상자, 스포너
  - **던전**: 이끼 낀 돌 방 + 몬스터 스포너 + 전리품 상자
  - **고대 금고**: 딥다크의 석벽돌 보물방 (다이아 장비 등 최고급 전리품)
  - 지하 호수, 용암호, 흑요석, 발광석
- **낮/밤 주기**, 하늘광/블록광 분리 조명 (횃불·용암·발광석·자수정이 빛을 냄)

## 시스템

- 서바이벌: 체력, 허기, 산소(수중), 낙하/용암/선인장/익사 피해, 사망 시 아이템 드랍 후 리스폰
- 도구 티어(나무→돌→철→금→다이아)와 채굴 제한 (예: 다이아몬드는 철 곡괭이 필요)
- 제작 40여 종 + 화로 제련, 갑옷, 활/화살, 양동이(물·용암), 부싯돌(TNT 점화), 나침반
- 몹: 좀비, 스켈레톤(원거리), 크리퍼(폭발), 거미, 슬라임, 박쥐, 워든 / 돼지, 소, 양, 닭
- 물·용암 유체 시뮬레이션 (용암+물 → 흑요석/돌), 모래·자갈 낙하
- 상자 보관, 몬스터 스포너, TNT 연쇄 폭발, 경험치
